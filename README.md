# 动一下 · Motion GIF Studio

静态图片动画工具。浏览器本地处理，支持 PNG/JPEG/WebP 上传、拖放、实时预览、弹性挤压/弹跳/摇摆、强度与幅度独立调整、速度、24/36/60 帧、256/512/768 像素 GIF 导出、取消导出与透明背景。

参考视频的动作是周期性的挤压拉伸与上下弹动，默认使用整图缩放、位移及逐行形变复现这种风格。没有自动人物分割或人体动作识别。保留已有透明背景；普通照片需先抠图。GIF 透明度为一位，半透明边缘按阈值处理。

## 本地运行

用任意静态 HTTP 服务器托管本目录，例如 `npx serve .`，打开显示的本地地址。无需构建。不要直接双击 HTML：模块与 Worker 需要 HTTP。

## 使用

上传图片 → 选择效果 → 调整强度、幅度、速度 → 设置尺寸和帧数 → 导出 GIF。暂停后可拖动进度条查看某一帧。导出时锁定参数快照，继续预览不会改变正在导出的动画。

## 部署

GitHub Pages 可直接从 main 分支根目录发布。所有资源使用相对路径，兼容仓库子路径。上传图片不会传到服务器。现代桌面及移动端浏览器需要支持 Canvas、Web Worker、OffscreenCanvas、createImageBitmap。

## 第三方组件

GIF 编码使用 gifenc（MIT），离线随站点提供，许可证见 vendor/LICENSE.gifenc。示例插画为本项目原创 SVG。参考视频仅用于动作分析，不随站点发布。
